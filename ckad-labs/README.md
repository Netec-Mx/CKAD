# CKAD Labs

Este directorio contiene los recursos utilizados durante las prácticas del curso Certified Kubernetes Application Developer (CKAD).

## Entorno utilizado

- Windows 11
- Visual Studio Code
- Git Bash
- WSL2
- Docker Desktop
- kubectl
- kind
- Kubernetes 1.36.1

La topología estándar es:

- 1 Control Plane
- 2 Worker Nodes

Nombre del cluster:

`ckad`

Contexto kubectl:

`kind-ckad`
